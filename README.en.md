# ThinkKoma

ThinkKoma starts thinking as soon as you launch it. `thinkkoma` with no subcommand is `live`: think → run → next think, forever. It authors its own missions from failing tests, syntax errors, logs, and — when the workspace is quiet — self-written propose / diagnose / explore thoughts. Stop with Ctrl+C, or `--max-cycles` in tests.

`thinkkoma drive` still patrols until quiet. Scoring uses plus (unit 6) and minus (unit 7) across ten viewpoints. Residuals backpropagate onto interpret / plan / act / verify / submit. Spec-ok requires oracle, safety, and integrity after independent reenact by both models.
